# Mazhar Shams | Data Specialist Portfolio

A modern, high-performance portfolio site designed for speed, accessibility, and high visual impact.

## ✨ Features
- **Premium Design**: Dark-mode aesthetic with glassmorphism and animated background blobs.
- **Glassmorphism UI**: Modern, sleek components with smooth transparency and blurs.
- **Optimized Performance**: Built with pure HTML, CSS, and JS for near-instant load times.
- **SEO Ready**: Semantic HTML, meta tags, and clean structures for search engines.
- **Vercel Ready**: Pre-configured for seamless hosting on Vercel.

## 🚀 Deployment

### Option 1: Vercel CLI (Recommended)
1. Install the Vercel CLI: `npm i -g vercel` (if you have Node installed locally).
2. Run `vercel` in this directory to deploy instantly.

### Option 2: GitHub Integration (Easiest)
1. Push this project to a GitHub, GitLab, or Bitbucket repository.
2. Go to [Vercel](https://vercel.com).
3. Select **"Import Project"** and connect your repository.
4. Deployment will happen automatically on every push!

## 📄 Customization
- **Resumé**: Replace `Mazhar_Shams_Resume.pdf` with your updated resumé.
- **Content**: Edit `index.html` to update your name, bio, and social links.
- **Experience**: Update the Professional Experience section in `index.html` with your latest roles and responsibilities.
